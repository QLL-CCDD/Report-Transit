# Home 第 0 轮水壶在落定时滑动约 7 cm（可行率被普查低估的原因）

诊断分支 `diag/kettle-kf-ik-seed-20261125`（只加日志，不合入），e，d7，seed 3101，64 env。

| 轮 | 摆放后水壶根 x 均值 | 30 步落定后水壶根 x 均值 | 最大位移 | 桌子 x | 关键帧可行 |
|---|---|---|---|---|---|
| 0 | 0.4300（= 指令） | **0.4987** | 7.44 cm | 0.4300 不动 | 7 / 64 |
| 1 | 0.4376 | 0.4404 | 2.25 cm | 0.4376 不动 | 21 / 64 |

- 第 0 轮所有 env 的水壶都沿 +x（远离机械臂）滑出约 6.9 cm（±0.27 cm），与朝向无关；后面各轮基本不动。
- 按钮 x ≥ 0.50 m 时全部不可行（seed 3101 八轮合计 0/127），所以第 0 轮可行率只有 4–7 / 64，其余轮 12–20 / 64。
- 普查（O-332）每个种子只跑 1 轮，所以 44/512 = 8.6% 全来自第 0 轮；seed 3101 第 1–7 轮合计 113/448 = 25%，已超过 v3 建库约 20% 的下限。
- 先排除了 IK 初值的假说：给关键帧链首个求解加上规格里的 IK 种子，8 轮可行数一个不变。

已验证：候选专家 seed 3102 × 16 轮（1024 提案，同 v3 第 6 步的规模）可行 242 个，够 200（见 05）。

## 定位（d，seed 3101，第 0 轮，`bisect-log.txt`）

| 变体 | 落定后水壶根 x | 第 0 轮关键帧可行 |
|---|---|---|
| 不加读数（候选 1c8e1a36 对照） | 0.4987（滑 6.9 cm） | 7 / 64 |
| 落定中每步读水壶根 / 水壶关节 / 水壶速度 / 机械臂 body | 0.4987 | 7 / 64 |
| start 之后、落定之前读一次水壶根 / 水壶关节 / 机械臂关节 | 0.4987 | 7 / 64 |
| **start 之后、落定之前读一次 `env.robot.data.body_pos_w`** | **0.4300（不滑）** | **13 / 64** |
| **候选修复：摆好场景后调一次 `staging.kinematics(env)`** | 0.428（按钮 x 均值，正常） | **9 / 64**（3 轮合计 41，成功 41，p95 590；不修 38 / 38 / 599） |

结论：`omnireset/full_trajectory.py::_home` 只在 `write_arm` 之后、摆物体之前调了 `kinematics`，摆好水壶后没有刷新；第 0 轮机械臂的 body 位姿缓冲是旧的，第一步落定用到它，结果水壶整体沿 +x 平移约 7 cm。第 1 轮起缓冲已经是新的，不出现。
候选修复是一行：`init_poses` / `_natural_mover` 之后加 `S.kinematics(env)`。这是所有题共用的 Home 摆位代码，按规则 82 先写提议，不在壶盖 PR 里改。
影响：所有只跑 1 轮的 Home 普查（O-332 各题）、`tasks validate` 的 home 步（3 轮里第 0 轮占 1/3）、v3 建库的第 0 轮，凡是第 0 轮有这个问题的题都受影响；别的题是否同样滑动没有查。
